# Gleam ftw! ⭐

I am a big fan of [Gleam](https://gleam.run/) & the [BEAM](https://www.erlang.org/blog/a-brief-beam-primer/) world!. 

Here are a few projects I've built!

*   **[gsh (Gleam SHell)](https://github.com/v4rm4n/gsh)**  

    *An interactive Gleam Shell.* Built directly on the BEAM VM, featuring expression evaluation, persistent runtime bindings, and multiline support. It brings a true interactive shell experience to the Gleam ecosystem.
*   **[gleebook](https://github.com/v4rm4n/gleebook)**  (This Project)

    *A modern documentation generator.* Inspired by Rust's `mdBook`, `gleebook` allows developers to write beautiful, deeply nested project guides with native Gleam syntax support.
